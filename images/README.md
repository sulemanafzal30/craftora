# Craftora image assets

This prototype currently references direct Unsplash image URLs from `js/data.js` and uses inline/local SVG fallbacks when an image fails. No local photography has been bundled. The subfolders are reserved for approved, locally hosted assets: `products/`, `artisans/`, `categories/`, `banners/`, and `icons/`. Replace remote image URLs only with assets that are licensed or otherwise authorized for use.
